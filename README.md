# 🚀 Backend Practice Repository

A collection of backend development exercises and mini-projects built while learning **Node.js**, **Express.js**, and **MongoDB**.

## 📚 Topics Covered

- REST API Development
- CRUD Operations
- Express Routing
- Route Parameters & Query Parameters
- Authentication & Password Hashing
- JWT Authentication
- MongoDB & Mongoose
- User Management
- Library Management System
- Leave Management System
- Student Attendance System
- Product Inventory System
- Task & To-Do APIs
- Backend-Frontend Integration

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Postman

## 📂 Repository Structure

Each folder contains a separate backend practice task or mini-project focusing on a specific concept.

## 🎯 Purpose

This repository documents my backend learning journey through hands-on practice, helping me strengthen my understanding of REST APIs, authentication, database operations, and real-world backend development.
